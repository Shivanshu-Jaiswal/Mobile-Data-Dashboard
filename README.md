# Mobile-Data-Dashboard
🚀 Mobile Sales Data Dashboard – Power BI Project 📊📱

Super excited to share the Mobile Sales Data Dashboard I recently built using Microsoft Power BI!

This dashboard provides a complete view of mobile sales performance, including:

 ✅ Total Sales & Transactions
 ✅ Monthly Quantity Trends
 ✅ Sales by City & Mobile Model
 ✅ Brand-wise Sales Analysis
 ✅ Payment Method Insights
 ✅ Customer Ratings Distribution
 ✅ Day-wise Sales Overview

Building this dashboard helped me understand how data can tell a powerful story when visualized the right way. It was a great hands-on experience in designing interactive reports, using DAX, and building meaningful insights.
